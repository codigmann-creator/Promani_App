¿Cómo funciona?

1. Pedido

Se selecciona el pedido en el que se utilizó el material.

2. Material

Se selecciona el material utilizado desde el inventario.

3. Cantidad

Se indica cuánto material fue utilizado en el trabajo.

4. Stock

El sistema descuenta automáticamente la cantidad utilizada del inventario.

Control

Si la cantidad solicitada supera el stock disponible, el sistema no permite registrar el consumo.
